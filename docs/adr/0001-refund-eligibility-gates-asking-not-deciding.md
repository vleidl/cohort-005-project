# Refund Eligibility decides when a learner may ask, not the outcome

The rules for raising a Refund Request (the 14-day window, the watch limit, the 50% completion limit, one Refund per course) are checked once, when the learner raises it. When an Admin approves or declines it later, those rules are not checked again. A request shouldn't expire because nobody reviewed it in time, or because the learner kept watching while it was open. Once a request is open, the outcome is the Admin's judgement. Don't "fix" approval to recheck the window.

## Exceptions

Sometimes a learner deserves a refund the rules don't allow. For that, an Admin raises an Exception Refund Request on the learner's behalf, with the Admin's own reason. It skips Refund Eligibility and must be decided by a different Admin. If the raising Admin is the only Admin, the request stays open with a warning until a second Admin exists. A sole Admin can't approve their own exception. We chose this over letting Admins issue Refunds directly, so every Refund still goes back to a Refund Request and its reason. An exception never overrides a claimed team seat (the seat belongs to the team) or an already Open Refund Request on the same purchase.
